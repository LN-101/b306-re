PROJECT SHOWCASE

作品展示 · 从入门练习到竞赛实战

从单片机小项目、传感器应用，到电机控制与移动平台调试，实验室鼓励同学在真实项目中积累工程经验。

FOC 驱动

以 STM32F405 为核心，面向 BLDC/PMSM 的力矩、速度与位置闭环控制，适用于底盘、云台与精密执行器。

平衡小车

基于 STM32F103C8T6、编码电机与 MPU6050，结合 PID 控制实现姿态平衡与运动控制。

电子罗盘

融合陀螺仪与磁力计数据，完成姿态解算与串口数据输出，可拓展到移动设备姿态感知。

送药小车

基于 STM32F407、光电传感器、K230 摄像头与编码电机，实现识别、循迹与多车协同。

AI-agent安全协作系统

本地部署 AI 模型与 Agent 智能体赋能机械臂安全作业，结合视觉感知与边缘计算实现安全协作。

六自由度仿生机械臂

融合可穿戴 IMU 与 RGB-D 视觉追踪实现人体姿态同步跟随，支持动作示教录制与板载轨迹时间戳复现。

FAQ & ANSWERS

常见问题答疑

关于招新、时间投入、考核管理与技术方向的答疑解惑。

电赛控制题不仅要求硬件稳定，核心胜负手在于控制算法和上层软件。我们深入研究 PID 调谐、经典/现代控制理论（LQR/卡尔曼滤波）、运动学解算、状态机调度、视觉辅助追踪（OpenMV / K230 / Linux 边缘计算） 等，将算法落地于电机、机械臂、无人机与移动底盘。
参与招新的同学需要良好兼顾课程、竞赛与生活，并保证稳定投入。若日常课程和学习已经较为疲惫，请慎重报名；进入考核后需服从教练团队安排，遵守实验室规章制度与阶段任务要求。
2026级基础培养入口更看重兴趣、态度、自学能力和持续投入，基础不完整也可以报名并通过训练逐步补齐；大二竞赛梯队属于补充招募，需要满足一定 C 语言、电路基础或项目/竞赛经历要求，并能完成后续阶段任务考核。
